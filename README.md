# シンプルな天気アプリ

## このアプリでできること

都市名を入力すると、天気気温がアイコンとともに表示されます。

[天気アプリ](https://graphicocolo.github.io/weather-simple/)

## 注意事項

天気データ取得のための API キーは OpenWeatherMap で取得し、定数ファイルに設定して使用しています。

APIキーはフロントエンドのコードに含まれるため、学習目的のプロジェクトです。実務では環境変数やバックエンド経由で管理します。
