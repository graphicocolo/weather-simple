# シンプルな天気アプリ

## このアプリでできること

都市名を入力すると、天気気温がアイコンとともに表示されます。

[天気アプリ](https://graphicocolo.github.io/weather-simple/)

天気データ取得のための API キーは OpenWeatherMap で取得、Cloudflare Workers でプロキシを作成して使用しています。
